NDL デジタルコレクションの個人送信資料で本文確認を行うときは、以下の分担で進める。
規約上、ログインと閲覧はユーザー本人のブラウザ操作で行う（エージェントによる自動ログイン・自動取得は行わない）。
利用者 ID・パスワード・認証コードはリポジトリ・チャット・メモリに記録しない。

## 前提

- NDL の登録利用者アカウント（本登録済み、国内居住）が必要
- 対象資料が「個人送信サービス対象」であること（`python3 scripts/ndl_search.py` で書誌を特定し、
  書誌ページ（ndlsearch.ndl.go.jp/books/...）を WebFetch して閲覧区分を確認する）。閲覧区分は
  「オンライン閲覧公開範囲」（インターネット公開／館内限定）と「デジタル化資料送信」（図書館・個人送信対象／対象外）の
  2 フィールドを併読して判定する。ページ内の facet 語彙やバッジ表示には全区分の文字列が出現するため、それだけで判定しない（誤判定の前例あり）

## 手順

### 1. 準備（エージェント）

1. 対象資料の書誌を `ndl_search.py` で確定し、デジコレの資料 URL を特定する
2. 確認したい主張（生没年・系譜・制定者など）を懸念台帳・考証結果から列挙し、
   **資料内検索用の検索語リスト**と**確認ポイントのチェックリスト**を提示する

### 2. ブラウザ操作（エージェント + ユーザー）

`scripts/browse.py`（軽量ブラウザ CLI、CDP 経由・抽出テキストのみ出力）で分担する:

1. エージェント: `python3 scripts/browse.py open` で可視ブラウザを起動し（永続プロファイルのため
   ログイン状態は維持される）、`goto` で https://dl.ndl.go.jp/ のログイン画面まで遷移する
2. **ユーザー: 開いたウィンドウで利用者 ID・パスワード・メール認証コードを直接入力**
   （資格情報を CLI・チャットに経由させない）。完了したらチャットで知らせる
3. エージェント: `goto` で資料へ遷移し、`find "<語>"` / `text --limit N` で該当箇所を確認する。
   ビューアが画像ベースでテキスト抽出できない場合は、`click` / `press` で資料内検索・頁送りを
   代行し、表示頁の内容はユーザーに読み上げてもらう
4. 確認できた記述は要点（頁番号付き）で扱う。長文の丸写しはしない

### 3. 反映（エージェント）

1. 報告された内容で主張の確度を再判定する（頁番号付きの本文確認は判定 A の根拠になり得る）
2. エンティティ本文・born/died・relations を更新し、`sources` の参照を確認する。
   references.yml のエントリに確認済みの書誌情報を補完する（頁番号は本文中の記述根拠として扱い、
   スキーマにないフィールドは追加しない）
3. 懸念台帳の該当項目を更新（解決なら `[x]` + コミットハッシュ）
4. `python3 scripts/validate.py` エラーゼロを確認しコミットする

## 注意

- 個人送信資料の画面キャプチャ・本文の大量転記・リポジトリへの保存は禁止（PDF 保存禁止と同じ扱い）
- 引用はユーザー報告の範囲内でのみ利用し、KB 本文は必ず自分の言葉で書く
- 国外からは個人送信サービスを利用できない
